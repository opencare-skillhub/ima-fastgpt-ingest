# 真实链路测试经验（2026-11-24）

本记录来自一次受控的 IMA → MinerU → FastGPT 联调：完整目录核验，一份扫描 PDF 下载，拆分后批量解析，一个短摘录的清洗、QA、embedding、检索及重复同步。完整书籍未全部入库，通用 QA 通过不表示完成专业医学审核。这里不包含原文、私有库标识或凭据。

## MinerU：先核验真实页数限制，再组批

本次客户端声称支持 600 页，但实际服务拒绝了 282 页文件，返回单文件最多 200 页。这个限制属于本次账户、模型及服务配置的实测，不能写死为所有版本的永久额度。

先读取 PDF 页数；超限时保留原 PDF，按当前服务额度拆分，记录每份原始物理页范围与 hash。此次两个 141 页文件一次申请批量上传 URL，分别 PUT，以一个 batch_id 轮询，再逐文件下载 ZIP。结果目录里的局部页号须映射回原 PDF 页号。不能把逐文件 PUT 误写成只能逐本手工解析，也不能把参数存在当作并发已经生效。

结果 CDN 若通过现有代理出现 TLS 错误，可独立诊断代理与直连。只有直连证书验证通过、目标域名可信时，才针对结果下载选择直连；不关闭 TLS 校验，不全局修改代理，不把任何主 API Key 发送给 CDN。ZIP 解包检查路径、文件总量和解压尺寸，避免直接无校验 extractall。

## 低于 85 分：清理后重评，不修改门槛

以上是默认质量门槛的测试记录。用户随后明确指示入库并忽略85分门槛：后续任务须记录用户豁免，不再因该分数阻止上传，仍保留原评分、版本、来源和待审校状态。该授权不等于专业医学审校或生产发布许可。

最新范围又收紧为“故事不要上传，必须是医疗规范信息，之前84分不要传”。因此完整解析结果可保留在项目output，但上传必须依据独立章节/页码准入清单；禁止上传整本叙事材料、个人经历、病例故事以及原84分候选。研究探索、历史版本或跨癌种内容不能自动包装为现行卵巢癌规范。

实际分拣还发现，患者开场叙述可能没有“故事/病例”关键词，而以人物称呼、经历或对话出现；仅用关键词扫描不充分。按目录和段落语义检查章节边界，排除无标记的个人叙述。一个物理页可能同时含上一章尾段和下一章开头，不能只选页码；起止页还须按明确标题切出所选章节。若草稿已误传，只撤回账本中本次创建且身份核对一致的条目，修正并重新检索后才收尾，不把上传成功当内容审核通过。

本次首版摘录 84 分被阻止上传；去掉非必要的历史叙述、假设示例、数字示例及个人故事，只保留对照原页的两段原文，再次评分为 85 分。书序、广告、重复目录等可作为清理候选，但不能为了提高评分删掉适用条件、否定词、安全提示、版本限制或不利证据。

保留清理前后文本、删除范围和原因、两次 QA 报告、评分模型及参数。重评只能检查清理后的实际文本；不得直接改 qa_score、循环抽到高分后隐藏失败记录，或上传 QA 模型补写的医学事实。固定门槛、红线检查和专业审核分别记录。未完成专业审核的测试片段只进入明确隔离的联调集合，不接患者生产检索。

## 清洗后再次保护来源

实测通用清洗器删除了以“来源：”开头的书名行，却保留了页码。清洗成功与 QA 高分不能证明出处完整。

在清洗前独立保存来源元数据；清洗后用确定性操作补回书名、来源库、原始物理页、章节、版本与审校状态，并对医学原文逐字比对。无版本信息应明确记为未知，不能推测。上传前验证所需字段，检索验收时也验证返回片段中的出处与风险标记。正文过长须分段时，每个可独立召回的块都应有可追溯的来源，不能只在整书开头写一次。

本次补回来源只修复元数据，未改写两段医学原文；最终检索重新核对了预期事实、书名、原 PDF 页码与待审校提醒。

## 版本修复：先验证新版本，再删除自己的旧条目

某些 fgkb 版本的 `FGKB_ON_CHANGE=replace` 会先删旧条目、再上传新文件，失败时可能出现空窗。使用前读当前实现，不能只根据配置名推断原子替换。

本次保留旧版，用新内容 hash 的文件名上传修正版；确认新文件检索命中并返回完整来源后，复核目标 dataset、父目录、旧条目 ID、名称、类型以及本次创建账本，仅删除这一条旧测试文件，再更新状态表。不可删除整个目录或其它条目。最后重新检索，并用同一 approved 目录重复同步，要求零新增、零更新、跳过已有文件且无同名副本。

## 验收与脱敏

- 上传成功、embedding 命中、已知事实正确、来源完整、幂等、生产发布是不同证据，分别记录。
- 向量相似度不是准确率。至少使用已知答案的问题核对事实，而非只看命中数量。
- 当前部署缺少统计字段时，不把空值写成零，也不虚构训练分片数；可记录实际纯向量检索证据与计数未取得。
- FastGPT 数据集的模型配置响应可能带有上游鉴权字段。输出只按白名单读取模型名、维度等必要字段；不要打印整个 `vectorModel`、`defaultConfig` 或原始异常响应。
- 公开仓库只保存通用步骤和脱敏结论；原件、全文、私有库 ID、共享链接、签名 URL、header、真实环境文件和远端响应保留在受控工作目录。
