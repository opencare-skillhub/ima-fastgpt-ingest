# 复用已有工具

本仓库不捆绑下列第三方技能，使用前检查本机版本和许可。

- fastgpt-content-processor：检查process-local和qa-ingest入口，处理本地MD。保留解析原件，不覆盖；必要时关闭LLM富化，不自动改写事实。
- fastgpt-kb-sync：负责doctor/check/sync/search、去重和增量同步；正式上传只保留这一个入口。

processor的QA目录可能在评分不通过时也写出文件，因此必须先形成独立approved目录，而不是同步整个qa-output。图谱或HTML表格可能被通用格式清洗规则误删，应对比样本或直接跳过不适用的清洗步骤。

整书按章保留父书与页映射后评分，避免超过模型上下文。评分、红线和专业审核共同决定准入；高分不证明OCR准确、指南仍有效或治疗适应证适用。

fgkb的环境优先级可能是CLI/环境变量高于.env。每次确认实例、目标名称、类型、ID和配置来源；不能依赖继承的默认dataset。某些版本的sync命令不支持--dataset-id或--source-dir，需要通过明确的项目配置/FGKB环境变量设置，以当前--help为准。

状态表身份规则可能默认识别NCT编号，书籍需另设身份映射。同名闸门可能挡住合法新版本，可使用带内容hash的物理文件名并保留逻辑映射；不要全局关闭去重。

MinerU客户端虽可能接受多文件/--list，某些版本的--concurrency只是保留参数，不能将传参当成并发已生效。旧批量脚本如使用无限timeout、无预算轮询、重新遍历目录匹配URL或直接extractall，应在无人值守使用前补齐映射、恢复及安全边界。
